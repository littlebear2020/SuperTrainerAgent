# Course Poster Design Skill

为企业培训课程设计科技风竖版宣传海报。

## 设计系统

### 配色方案（默认科技风）
- **背景**：深空黑 `#060a12`
- **主色**：冷青色 `#00d4ff`（线条、节点、边框）
- **强调色**：琥珀色 `#ffb800`（仅 2-3 处点缀，用于关键信息高亮）
- **文字**：白色 `#ffffff`（标题）、`rgba(255,255,255,0.55)`（副标题）、`rgba(255,255,255,0.5)`（描述）

### 字体系统
字体目录：`/mnt/skills/public/canvas-design/canvas-fonts/`

| 用途 | 字体 | 风格 |
|------|------|------|
| 主标题 | BigShoulders-Bold | 粗体大字，120-140px |
| 副标题 | InstrumentSans-Regular | 宽字距，30-34px |
| 信息标签 | GeistMono-Regular | 等宽，12-14px |
| 数字信息 | Tektur-Medium | 40-50px |
| 卡片内容 | InstrumentSans-Bold/Regular | 22-24px 标题，17-18px 描述 |
| 装饰文字 | Lora-Italic | 衬线斜体，底部引言 |

### 画布尺寸
默认 1080×1920px（竖版），适合手机/社交媒体传播。

## 设计哲学

采用 **Systemic Pulse** 美学：网络节点拓扑 + 几何装饰 + 极简信息架构。

**核心原则：**
- 文字占画面主体，图形作为背景氛围层
- 留白有目的性，不是"空"而是呼吸空间
- 60% 视觉 + 30% 文字 + 10% 留白
- 每个元素都要有精确对齐，不允许重叠

## 必要信息收集

每次设计前，确认以下信息（缺失部分主动询问或合理补充）：

**必须由用户提供：**
- 课程主题/标题
- 分享日期
- 课程时长

**可以合理补充：**
- 讲师姓名（如有照片更好）
- 2-4 个课程内容要点
- 课程副标题/Slogan

**固定元素（自动生成）：**
- "Enterprise AI Training" 标签
- 年份标记
- 四角定位框
- 底部引言（可选）

## 实现方式

### 技术栈
- HTML + CSS 编写海报
- SVG 绘制网络拓扑图形
- Chrome headless 截图生成 PNG

### 截图命令
```bash
/opt/chrome-headless-shell/chrome-headless-shell \
  --headless=new --disable-gpu --no-sandbox \
  --screenshot=OUTPUT_PATH.png \
  --window-size=1080,1920 \
  file:///INPUT_PATH.html
```

### 输出
- HTML 源文件：`/mnt/user-data/workspace/course-poster/<name>.html`
- PNG 海报：`/mnt/user-data/workspace/course-poster/<name>.png`

## 照片处理

如果用户提供讲师照片：
- 使用**圆形裁剪**（`border-radius: 50%`）
- 配合双层光环装饰（内圈实线 + 外圈脉冲动画）
- 青色发光阴影（`box-shadow`）
- 位置：中间区域偏右侧，与左侧标题文字错开
- 照片下方放讲师姓名（Tektur 字体，20-22px，琥珀色）
- 注意：照片不要与文字重叠

## SVG 图形元素

### 网络拓扑（必备）
- 三层嵌套六边形（不同透明度描边）
- 虚线圆环轨道
- 节点圆点（不同大小/透明度）
- 连接线
- 流动粒子动画（`<animateMotion>`）

### 几何装饰（散布）
- 三角形 `△`
- 菱形 `◇`
- 十字 `+`
- 小方块 `□`
- 分布在画面边缘，低透明度

### 角标定位框
四个角的 L 形边框，1-2px，低透明度青色。

## 常见问题与经验

### 字体大小
- 主标题必须 ≥120px，绝不能太小
- 所有文字都要比直觉再大一号
- 信息标签（日期、时长）≥40px

### 画面密度
- 宁可密集也不要空洞
- 底部信息不要堆叠，可以竖排或嵌入标题下方
- 内容卡片间距 20-24px

### 迭代流程
1. 先出初版 → 用户反馈
2. 常见修改：字号放大、元素位置调整、照片位置
3. 每次修改后立即截图预览
4. 使用 Chrome headless 截图，不要用其他工具

### 字体加载
必须使用 `@font-face` 从本地字体目录加载，不能依赖系统字体。每个字体需要 Regular 和 Bold 两档。
