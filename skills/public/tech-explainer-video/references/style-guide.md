# 科技风格配置指南

## 领域风格匹配

### 人工智能
- **配色**: 深蓝 + 青蓝 + 白色
- **元素**: 神经网络节点、数据流、芯片纹理、代码流动
- **风格词**: sci-fi technology, data visualization style, deep blue background, glowing cyan lines, particle effects, futuristic, 8k

### 量子技术
- **配色**: 深紫 + 品红 + 青色
- **元素**: 量子态粒子、波动效果、多维空间、能量环
- **风格词**: mysterious quantum technology, purple-blue gradient, wave particle effects, multidimensional space, ethereal glow

### 生物科技
- **配色**: 深绿 + 青绿 + 白色
- **元素**: DNA双螺旋、细胞结构、分子模型、微观粒子
- **风格词**: life science style, green technology, microscopic world, DNA helix, molecular structure, bioluminescent

### 新能源
- **配色**: 深蓝 + 橙黄 + 白色
- **元素**: 能量流动、电池图标、太阳光芒、电流线
- **风格词**: clean energy style, light flow effects, blue-orange palette, glowing energy waves, solar rays

### 航天科技
- **配色**: 深蓝 + 橙色 + 白色
- **元素**: 星空、火箭、卫星轨道、行星、星云
- **风格词**: cosmic technology, starfield background, deep space, rocket trails, planetary system, cinematic space

### 半导体/芯片
- **配色**: 深灰 + 金色 + 青蓝
- **元素**: 电路纹理、芯片结构、光刻图案、晶圆
- **风格词**: precision technology, circuit patterns, metallic texture, golden traces on dark silicon, microchip close-up

### 新材料
- **配色**: 深灰 + 银色 + 青绿
- **元素**: 分子结构、晶体纹理、纳米粒子、原子排列
- **风格词**: microscopic technology, material texture, precision structure, crystalline lattice, nano particles

### 通用科技
- **配色**: 深蓝 + 青蓝 + 白色
- **元素**: 数据流、粒子效果、网格纹理、全息投影
- **风格词**: modern technology, data visualization, blue tones, holographic display, particle flow, futuristic

## 提示词模板

### 生图提示词格式
```
{风格词}; {主体描述}; {镜头描述}; {环境描述}; 8k, high quality, 16:9
```

**示例（AI领域）**:
```
Sci-fi technology, data visualization style, deep blue background, glowing cyan lines; neural network nodes connecting in 3D space, data particles flowing between nodes; medium shot, slow push-in; dark blue tech background, floating data lines, particle effects, futuristic space. 8k, high quality, 16:9
```

### 图生视频提示词格式
```
{镜头运动} + {主体运动} + {效果细节}
```

**示例（AI领域）**:
```
Slow push-in camera, neural network nodes emitting cyan light, data particles flowing between nodes, glowing data lines floating in deep blue space, camera reveals central processing core, sci-fi light effects, data flow animation
```

## 镜头类型参考

| 镜头 | 英文 | 适用场景 | 情绪 |
|------|------|---------|------|
| 推镜头 | Push-in / Zoom-in | 强调重点、揭示细节 | 专注、震撼 |
| 拉镜头 | Pull-out / Zoom-out | 展示全貌、呈现规模 | 开阔、惊叹 |
| 移镜头 | Pan / Truck | 展示流程、空间移动 | 流畅、引导 |
| 环绕镜头 | Orbit / 360 rotation | 展示三维结构 | 全面、立体 |
| 固定镜头 | Static / Locked | 展示数据、图表 | 稳定、专业 |

## 差异化设计规则

1. **相邻分镜必须使用不同主体元素**（如：节点→数据流→芯片→全息图）
2. **禁止连续3个分镜使用相同镜头运动**
3. **每个章节至少包含2种可视化类型**（数据动画/概念动画/图表/流程图）
4. **色彩在主色调基础上，不同章节调整强调色**
