# 科技领域类比库

为科普脚本撰写提供跨领域类比，帮助观众理解复杂技术概念。

## 使用规则

1. 每个视频选定类比后贯穿全文，禁止中途更换
2. 首次使用时完整呈现类比，后续可简略提及
3. 类比必须基于原文概念，不能脱离原文自行发挥
