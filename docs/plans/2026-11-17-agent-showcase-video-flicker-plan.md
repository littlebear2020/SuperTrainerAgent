# Agent Showcase 课程视频闪帧修复计划

> **状态**：已执行（2026-11-17；变更日志：`docs/changelog/changelog-2026-11-17-agent-showcase-video-flicker.md`）。
> **TL;DR**：课程视频第一个案例在 0.10/0.27/0.50/4.17/4.27/4.63/4.97/13.90s 出现单帧 2×2 重影闪帧；用后一帧替换这些坏帧并重编码，时长/音轨不变；同时修复第三个案例同类的 1 帧残影。

## 一、诊断

用户反馈课程视频第一个案例播放时“有的画面会闪一下”。逐帧检查 `videos/v1.mp4`（1280×720/30fps/968 帧）：

- 单帧异常检测（前后帧差远大于跳帧差）命中 n=3、8、15、125、128、139、149、417，对应 t≈0.10/0.27/0.50/4.17/4.27/4.63/4.97/13.90s。
- 抽帧确认这些帧把同一页 PPT 以 2×2 四宫格/双画面重影的方式渲染出来，下一帧恢复正常，所以播放时像“闪一下”。
- `v3.mp4` 也有 1 帧同类残影（n=1098，t≈36.60s）；`v2.mp4` 未检出。

## 二、修复

- 用后一帧替换坏帧（保持帧数与时间轴不变），重新编码 H.264/yuvj420p 30fps，音轨直接 copy。
- v1 替换 8 帧：3,8,15,125,128,139,149,417。
- v3 替换 1 帧：1098。
- 不用交叉淡化/补帧，避免引入新的运动模糊；单帧替换在 PPT 课程视频里不可感知。

## 三、验收

- `ffprobe`：v1 = 968 帧 / 32.320000s；v3 = 1171 帧 / 39.082667s（与 `showcase.ts` 的 `durationSeconds` 一致）。
- 单帧异常检测：v1 8 → 0；v3 1 → 0；v2 0。
- 抽帧检查：0.1–0.5s、4.1–5.1s、13.9s 附近不再出现 2×2 重影。
- `pnpm test` 定向 showcase 资产测试通过；素材总量 16,962,605 bytes（<20MB）。
- 本地浏览器播放：`duration=32.32`、`readyState=4`、`videoError=null`；4.6s 抽帧无重影、无 console error。
- 目标 E2E `41 passed (52.9s)`。

## 四、说明

- 只修 v1/v3 的坏帧，不改视频内容、时长、海报与文案；v2 未动。
- 重编码 CRF 17，文件略增大约 1.28MB（总预算仍充足）。
- 一次性修复脚本不进入仓库。
