# Agent showcase 素材

本目录是四个 Agent 新会话引导页的静态真实产物，共 **58 个媒体文件**。案例与路径的单一事实源是 `frontend/src/core/agents/showcase.ts`。

## 来源与授权

- 课程视频：项目内为 ListenHub Demo 生成的 Remotion 成片与 WebP 海报，2026-11-16 生成；2026-11-17 修复 v1 的 8 帧、v3 的 1 帧转场残影（单帧 2×2 重影），用后一帧替换，时长与音轨不变。
- PPT：项目内生成的三份原生可编辑 PPTX 及逐页 WebP 预览，2026-11-17 重做版式与字体层级（本轮未再改 PPT 素材）。`template-360-ai-v4.pptx` 基于用户提供的 360 模板改造，保留品牌封面、页眉标识与绿色视觉语言；用户已于 2026-11-17 明确授权随本项目分发。
- 播客：项目内生成的四期节目，使用豆包 TTS 男声/女声，2026-11-16 生成；无声音克隆、无背景音乐。
- 视觉：2026-11-17 重做竖版海报、知识卡与信息图（精确排版，1152/2048 宽画布导出），重绘两张 SVG 结构图；两页漫画沿用 2026-11-16 的生图产物。2026-11-17 第二轮按用户反馈调整底色：薄荷笔记卡、靛紫玻璃卡、冰蓝信息图、赤陶路线图、深青结构图、淡紫蓝图，避免黑底与米色重复。
- 人物：项目内为 ListenHub Demo 生成的四张人物图，2026-11-16 生成。本批离线把与边缘连通的近白背景替换为浅靛渐变，并裁出透明圆角；运行时不抠图。

这些素材仅用于本项目的产品案例展示、测试与文档，不包含密钥或用户私密数据。外部调研链接仅作为节目与视频的来源说明，网页内容不随素材再分发。

## 文件与压缩口径

- 本目录共 54 个案例媒体 + 4 个人物，实际媒体总量 **16,962,605 bytes（16.96 MB，16.18 MiB）**，58 个文件；`README.md` 不计入媒体清单。未迁移 `visual/test-*`、旧版 `poster-agent-dark.jpg`、结构图 PNG、`ppt-art/`、Remotion 工程或 `bundle.html`。
- 视频保留来源 H.264/AAC MP4，1280×720；海报与预览使用 WebP。
- 视觉预览使用 WebP；原图 JPG 与结构图 SVG 仅在用户打开或下载时加载。
- PPTX 分别为 236,985 / 437,726 / 467,022 bytes，按十进制 KB/MB 展示；逐页预览为 1920×1080 WebP。
- MP3 保留来源 64 kbps 编码。

资产数量、路径集合、PPTX 原始字节数与 20,000,000 bytes 总预算由 `frontend/tests/unit/core/agents/showcase.test.ts` 校验。
