# Agent showcase 素材

本目录是四个 Agent 新会话引导页的静态真实产物，共 **58 个媒体文件**。案例与路径的单一事实源是 `frontend/src/core/agents/showcase.ts`。

## 来源与授权

- 课程视频：项目内为 ListenHub Demo 生成的 Remotion 成片与 WebP 海报，2026-11-16 生成。
- PPT：项目内生成的三份原生可编辑 PPTX 及逐页 WebP 预览，2026-11-16 生成。`template-360-ai-v3.pptx` 基于用户提供的 360 模板改造；用户已于 2026-11-17 明确授权随本项目分发。
- 播客：项目内生成的四期节目，使用豆包 TTS 男声/女声，2026-11-16 生成；无声音克隆、无背景音乐。
- 视觉：项目内使用 360 生图模型生成的海报、知识卡、漫画、信息图，以及项目生成的 SVG 结构图，2026-11-16 生成。
- 人物：项目内为 ListenHub Demo 生成的四张人物图，2026-11-16 生成。本批离线把与边缘连通的近白背景替换为浅靛渐变，并裁出透明圆角；运行时不抠图。

这些素材仅用于本项目的产品案例展示、测试与文档，不包含密钥或用户私密数据。外部调研链接仅作为节目与视频的来源说明，网页内容不随素材再分发。

## 文件与压缩口径

- 来源选定清单：54 个案例媒体 + 4 个人物，共 15,318,890 bytes；未迁移 `visual/test-*`、旧版 `poster-agent-dark.jpg`、结构图 PNG、`ppt-art/`、Remotion 工程或 `bundle.html`。
- 人物离线重压缩后，本目录实际媒体总量为 **15,284,192 bytes（15.28 MB，14.58 MiB）**，58 个文件；`README.md` 不计入媒体清单。
- 视频保留来源 H.264/AAC MP4，1280×720；海报与预览使用 WebP。
- 视觉预览使用 WebP；原图 JPG 与结构图 SVG 仅在用户打开或下载时加载。
- PPTX 分别为 200,540 / 308,973 / 465,113 bytes，按十进制 KB/MB 展示。
- MP3 保留来源 64 kbps 编码。

资产数量、路径集合、PPTX 原始字节数与 20,000,000 bytes 总预算由 `frontend/tests/unit/core/agents/showcase.test.ts` 校验。
